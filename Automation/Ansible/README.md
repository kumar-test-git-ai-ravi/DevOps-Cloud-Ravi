# What is Ansible
Ansible is an open-source automation toll used to manages servers,deploy applications and configure system
Systems:
- Linux servers
- windows machines
Network devices:
- Routers
-  Switches
-  Firewall
-  Load balancers
## Purpose
Used to automate the qa task
Used for configuration management
used for application deployment
## How it works
it is agentless 
Uses SSH to connect to remote machine
Execute tasks defined in playbooks
## Key component
- Control Node: Machine where Ansible is installed
- Managed Nodes: Target machine
- Inventory:List of servers
- Playbook: YAML files with task
- Modules: in-build function for tasks
## Language used
YAML: for playbooks
## Advantages
Easy to use
No agent installation needed
Fast automation of tasks
Reduces manualy work by 30%
